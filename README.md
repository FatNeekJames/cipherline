# CIPHERLINE

Route the signal. Break the system.

Cipherline is a tactical browser puzzle game built around alternating row-and-column code routing. Study an evolving 5×5-to-9×9 matrix, compress target routines into a limited buffer, and finish the route before the breach timer expires.

## Features

- 30-level campaign across five network tiers
- Procedurally generated, solver-validated puzzles
- Escalating matrix sizes, ICE-locked cells, live-start traces, and per-input time penalties
- Endless fracture mode
- Overlapping target sequences, scoring, hints, rewards, and achievements
- Full keyboard, mouse, and touch controls
- Local progress saving
- Reduced-motion, high-contrast, alternate-palette, and untimed modes

## Controls

- `WASD` or arrow keys — move within the active row or column
- `Space` or `Enter` — select a code
- `H` — trace a hint
- `R` — restart the current node
- `Esc` — pause

## Development

```bash
pnpm install
pnpm dev
```

Run the puzzle-engine checks with `pnpm test` and create a production build with `pnpm build`.

## Originality

Cipherline uses an original name, interface, progression system, artwork, and fictional setting. Its neon-noir presentation and alternating-axis puzzle mechanic are presented as an independent game rather than an official adaptation of another property.
